# --- Public internet-research scanners -------------------------------------
# We REFUSE for these scanner-research zones rather than bluff-answer.
# The queries are still fully logged (handler=exempt, response_kind=REFUSED)
# and surfaced in the morning report's "research scanners" section. The
# rationale is yin/yang: honeycow is the passive listener, these orgs are
# the active scanners, and we don't want to falsely validate amplifier paths
# in their open-resolver / open-service reports.

# --- Canonical real-world authority zones (open-resolver tells) -----------
# Scanners fingerprint open resolvers by sending TXT/A queries for famous
# zones they know we are NOT authoritative for (`TXT google.com.`,
# `TXT cloudflare.com.`, etc.). A real off-zone authoritative would
# return REFUSED. Without this list we synthesize an answer — the textbook
# "yes I'm an open resolver" signature that gets fed into
# DigitalOcean/Shadowserver-style abuse pipelines. REFUSE-ing here costs
# us nothing legitimate and removes the loudest signal.
